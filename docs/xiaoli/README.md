# 小梨免费对话预览

这是独立的 `#xiaoli` 体验页，保留百科、东方色谱、绣境奇遇及原有真实联网功能。经维护者批准后由 main 的 GitHub Actions 发布正式站点。不需要 API 密钥或付费账号。

## 已实现

- 默认使用原有 **155 条**可溯源刺绣资料。此版本没有新增未经核验的文化事实，也没有宣称知识数量已扩大。
- 问候、资料不足提示、出处展开、简单/详细讲解、上一问的简化追问、针法课堂入口。
- 对话仅在当前标签页的运行内存保存；站内续聊快照保留最近40条消息，阅读后可返回接着聊，刷新或关闭标签页清除。可选择仅在本机记住讲解偏好。重新聊清除话题；停止和离开小梨页会终止模型/语音任务，不清理游戏存档。
- 可选 WebLLM + Qwen2.5-0.5B 本机推理。用户主动启用后下载约 300MB；使用 Web Worker、2048 上下文、90 秒超时和内存释放。关闭模型恢复小梨 3D 形象，避免两者竞争显存。
- 输出检查引用编号、来源已有数字、明显新增的绝对化表述，以及将来源中不明确的起源说成确定结论的情况。不通过就回退资料摘要。**这些规则不是语义事实核验，模型回答仍须核对出处。**
- 可选本机 WASM 中文语音，同一女声提供舒缓/明快两种语速。生成后点击播放器，不自动播放；可朗读上一条回答。
- 语音训练数据有非商业限制，仅在本机做研究试听；普通构建排除整个声音目录，Git 忽略模型权重。

## 运行

使用 Node 24（与项目 CI 一致），安装依赖后：

```powershell
npm ci
npm run typecheck
npm test
npm run build
```

部署 `_site`；二级路径为 `/lihuajiyexiou/`，预览路由为 `#xiaoli`。普通构建不含本机试听权重，文字功能和用户自行启用的浏览器模型可用。不要把本机研究试听包当作已许可商用的配音包发布。

仅本机非商业试听：

```powershell
npm run prepare:xiaoli-voice
$env:VITE_XIAOLI_VOICE='true'
npm run build
Remove-Item Env:VITE_XIAOLI_VOICE
```

准备脚本从官方 release 下载、核对 SHA-256、保留运行库许可证与模型来源；也接受已有归档路径。需要系统自带 `tar`。不将本机预览服务地址写入网页产品代码。

## 隐私与离线边界

本机模型问答不发送给大模型 API，声音文本也不上传。首次模型下载连接 Hugging Face/MLC 官方托管域名，主站已有云存档等功能保持原配置。启用模型需要 WebGPU；不支持或失败时继续资料问答。缓存可由“清理此模型的下载缓存”删除，不影响游戏数据。浏览器可能自动回收缓存，不能承诺永久离线可用。

## 验证范围

`evaluation-cases.json` 的 100 条覆盖真实资料检索、主题追问、问候、资料不足和越界问题，由 `scripts/xiaoli-preview.test.mjs` 执行。它们不是 100 道大模型质量评测。另有浏览器中真实下载/推理、WASM 合成 WAV、桌面和 390px 手机检查。

本机是 8GB RAM、GTX1050 2GB 设备，小模型实际回答需要数十秒，引用缺失会回退；不等同豆包或大型云模型。自然度需要用户试听判断。本阶段没有完整语音识别、免手持通话或精确口型同步。后续知识扩展应从授权的博物馆/非遗资料逐条补齐出处，而不是把模型生成内容直接写成知识库。

## 借鉴与许可

- [WebLLM](https://github.com/mlc-ai/web-llm)：Apache-2.0；项目固定 `@mlc-ai/web-llm@0.2.87`，用户点击后才加载推理代码和权重。
- [Qwen2.5-0.5B-Instruct](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct)：Apache-2.0；运行时使用官方 MLC 目录中的 `Qwen2.5-0.5B-Instruct-q4f32_1-MLC`。
- [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)：Apache-2.0 运行库；固定 v2.0.1 WASM release。
- [Matcha Chinese Baker 模型说明](https://huggingface.co/csukuangfj/matcha-icefall-zh-baker)：DataBaker 训练数据标注仅非商业使用，不能因运行库开源就推断声音可商用。
- 原项目文化资料、3D 模型和美术资源沿用原始来源与授权范围；本功能不改变其许可。

## 专题、连续讲解与站内导览

本轮增加 `content/xiaoli-topics.json` 中的12个专题，覆盖绣种区别、针法入门、作品欣赏、历史人物、材料配色。专题仅引用已有资料ID，每条简明转述也绑定记录ID；不宣称原有155条资料数量增加。构建中的 `validate-xiaoli-topics.mjs` 阻止缺少出处、虚构记录和演示错配。

“我还是不懂／换个说法”显示简明转述；“详细一点”补充原记录事实与明确标注的阅读提示；“给我看看”显示正确针法图示或可选馆藏图片；“出处在哪里”保留当前话题并列出来源。问候与致谢不抢走话题，明确新主题会切换，不支持的具体问题不会回退到无关旧主题。专题追问直接使用已核验材料，不等待小模型重写。

散套针、滚针、平针分别链接现有 `demo-santao-pear-petal`、`demo-gun-basic`、`demo-straight-basic`。静态示意图根据同一练习的针迹坐标绘制，注明项目数字示意；不代表实物历史复原。进入演示不自动记为完成学习。作品链接指向确切馆藏记录；图像复用现有 Met 许可/编号核验模块，仅点击后请求。材料配色链接现有东方色谱，数字色值不冒充绣线配方。站内返回小梨可保留正在讨论的主题。

新增7组测试覆盖12专题的简明/详细回答、完整追问链、切换主题、未知事实保护、真实目标映射、会话清除与上限。完整单元测试共130项；真实浏览器另验证三种针法的目标选择、色谱、作品、返回续聊、刷新清除与390px手机布局。

公开发布时，百科页提供“和小梨聊聊”入口。新增代码许可范围见 [OPEN_SOURCE.md](../../OPEN_SOURCE.md)；普通构建不含本机试听权重。

## 日常问法与设备朗读

支持“请问…呀”“能不能讲简单一点”“这个怎么绣”等口语；当前没有话题或比较对象不明确时先澄清。礼貌前后缀不会移除年份、人物、获奖等事实限定，未知事实仍走依据不足分支。

资料摘要优先直接显示。即使本机模型已加载，也只在点击“用本机模型再解释”时生成改写，保持引用检查及失败回退。模型的下载大小与能力边界不变。

公开版提供设备朗读：仅列出 `localService=true` 的中文系统声音，支持声音选择、三档语速、分句停顿和停止。新问题、重新聊、离开页面会取消本站当前朗读；不自动播放。没有本地中文声音时明确提示，不自动切换远端语音。此功能不需要 Baker 模型包，不承诺达到自然语音模型质量。接口依据：[MDN getVoices](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices)、[localService](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisVoice/localService)。

原有 155 条资料保持不变；此次扩展的是问法和讲解路径，未将未经核验的模型生成内容加入知识库。

## 新手引导与专题扩展（2026-11-10）

专题从12个扩展为18个，新增工具、制作工序、打籽针、套针分型、钉线与钉针、网针。沿用既有155条原始资料，工具及流程核对苏州非遗官方项目页，针法沿用故宫资料及原来源ID。没有增加未经核验的文化事实。概览类专题完整呈现最多四条引用，避免工具或分型被简短回答截断。

“我是零基础，从哪里开始”提供本站入门阅读建议，从平针开始并可继续看演示或工具；“滚针怎么练”等具名问题直接进入对应示意与真实练习。“换一个”在当前分类仅有一个专题时会换到其他专题，不原地重复。

首屏提供“直接提问”焦点跳转，手机缩短角色区与对话滚动区；角色载入时显示提示，失败时可以重试，文字问答始终可用。加载状态由实际 GLB 成功或失败事件驱动，离开页面后不更新旧组件。

## 连续追问与指代选择（2026-11-11）

多条资料回答之后，“第一种／第二种／第三种／第四种呢”按刚才实际显示的记录顺序选中一项；后续简明解释、详情、指代、出处和阅读操作保持在该项。超出显示范围、没有前文或只讲过一项时先澄清。“另一种呢”列出刚才的名称与顺序选择，不猜用户想指哪一项。

只有“为什么／为什么会这样”等不含具体命题的简短追问，会先询问想了解哪一点的原因；不把相关资料摘要当成因果解释。明确人物、年份、奖项等限定不会被这些口语规则吞掉。遇到依据不足的问题后，指代选择不会跨过它恢复之前的主题；致谢可以保留主题。

新增5组真实资料回归测试，合计138项单元测试通过。Chromium验证比较→澄清→选第二项→简化→出处、为什么→实际滚针演示→返回、不支持的年份问题→拒绝猜测、手机第四项选择。原155条资料、18个专题及语音方案保持不变。

## 口语检索、出处摘录和纠错（2026-11-11）

采用 MiniSearch 7.2.0（MIT）在浏览器内索引155条资料和18专题，按中文分词、复合词与字段权重查找候选；搜索索引按资料对象缓存，查询不发到服务器。实现参考：https://github.com/lucaong/minisearch 。中文分词不可用时保留双字回退。此功能是全文检索与已审核问法映射，不宣称语义大模型理解。

明确、完整的苏绣工具/步骤口语可映射已审核专题，并提示苏绣范围；“绣之前准备什么”等含糊问法先显示最多3项候选，点击后重新验证候选ID与原查询绑定，再讲对应资料。低匹配及无依据日期/获奖等问题不自动转为文化事实。候选检索不改动原始155条资料。

每个〔数字〕引用现在是键盘可用的按钮，可展开并聚焦对应出处卡。卡片区分“来源原文·短摘”和“本站资料摘录·据来源整理，非逐字原文”。苏州非遗页面 https://szfy.wglj.suzhou.com.cn/index.php/fy-project/8 本轮核验4段很短的原文，关联4种工具和工艺流程共5条记录；其余记录保留整理摘录与原网页链接，不能宣称全部已有馆方原文。新增来源URL/记录ID/核验日期由构建脚本校验，逐字一致性由此次人工网页核对完成，构建不联网冒充核验。

最新一条回答提供三个真实操作：“太复杂”沿用出处简化；“想看示范”进入对应演示引导；“没答到点上”撤销当前指代依据，提出候选并把原问题放回输入框供改写。不上传反馈、不记录浏览器持久反馈、不改变游戏或云存档。页面会话的关闭/刷新清除规则保持不变。

MiniSearch版权与许可随网站包含在 assets/licenses/minisearch-MIT.txt。来源短摘不适用项目代码MIT许可。生产依赖审计未报告漏洞；开发工具链的既有审计项未在本轮强制升级。
