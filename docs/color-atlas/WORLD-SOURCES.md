# 梨花季 · 世界艺术与文化配色 · 来源说明

2026-10-20，按用户确认的“世界艺术家 + 艺术风格 + 各国家/文化地区纹样”方向扩展东方色谱。

## 资料定义

1. **世界纹样取色**：读取 `content/patterns.json` 中现有的 1,088 份目录记录；仅选图片实际在仓库、且逐条标注 Cleveland Museum of Art CC0 或 The Met Public Domain 的记录。按原作品编号去重。从各馆藏作品数字图像取六个颜色，不把美国博物馆馆藏误称为美国来源，也不把目录的广域文化区划冒充具体国家。
2. **画家作品取色**：从公开官方 API 验证 `isPublicDomain` / `is_public_domain` 为真、可用图像地址和画家姓名，再下载缩小版图像、计算颜色。许可失败、无图像或请求被拒绝的作品跳过；无图片绝不捏造色值。
3. **艺术风格灵感色**：24套由梨花季编排的原创六色搭配，如“莫兰迪式”低饱和、印象派/后印象派式、浮世绘、装饰艺术和不同文化纹样灵感。它们**不是**任何具名画家的某件作品实测色，也没有获得相关画家遗产管理机构背书。

## 权威数据与开放图片来源

- Cleveland Museum of Art Open Access https://www.clevelandart.org/open-access — 只读取本库已有 CC0 标记且真实存在的图片。
- The Metropolitan Museum of Art Open Access https://www.metmuseum.org/about-the-met/policies-and-documents/open-access — 官网对象 API 的 `isPublicDomain` 和图片URL，过滤空图像。
- The Art Institute of Chicago API https://api.artic.edu/docs/ — 取 `is_public_domain` 和 `image_id`；IIIF仅使用已获开放标记的图片。
- 已有一批 **100 件 CMA CC0 馆藏作品**的色谱存放在 `content/color-atlas-museum.json`。本次对其原作编号去重，保留原有六色方案不修改。
- 第三方 MIT 色谱数据的署名和许可保留在 `docs/color-atlas/SOURCES.md`。

## 数据文件和自动化

- `scripts/build-world-color-atlas.py`：单机可复现的来源审计、色彩取样和艺术风格原创预设生成工具。
- `docs/color-atlas/world-source-audit.json`：逐条列出 1,088 份目录的许可证、广域地区、是否有本地图像、是否可作为取色来源。
- `content/color-atlas-world.json`：原作品信息、所在馆、画家、创作时间（馆方提供时）、来源 URL、授权和六色值。
- `assets/world-palette-presets.js`：为故事纹样生成器提供新的数字六色方案。
- `assets/color-atlas/artworks/...`：从 API 核验且允许复用的艺术作品 WebP 小图。图片对应其来源原件，而非AI虚构作品。
- `.github/workflows/build-world-color-atlas.yml`：自动化构建、来源校验、生成数据并回写到 GitHub。

## 不得混淆的边界

**莫兰迪艺术作品≠莫兰迪式原创配色。** 画家的姓名或艺术风格名不构成图片自由转载许可；尤其对于较晚去世的画家，不能把尚在版权期的画作直接放入图库。站内“莫兰迪式”明确标成“原创数字风格灵感”，没有作品图片或官方实测色的声称。

**画家国籍≠作品产地≠博物馆所在地。** 页面明确标明数据来源的“文化地区”或者画家国籍，不对旧目录缺失的国家字段进行强行推断。

**电子图片样色≠文物原色≠真丝绣线色号。** 六色结果来自压缩数码图像的 RGB 色块，不能当作颜料/纤维物理测色或者工艺施工配方。

**所有新增方案带来源。** 真实艺术品必须展示原作链接、馆方名称和真实许可证；原创风格提案明确标注“本站原创”。如官方接口不可达，脚本会记录失败并跳过，不会用其他作者作品假冒官方开源。

## 2026-10-20 追加开发：逐件大都会云纹、局部取色与色彩质量审计

- **大都会25件原始作品**：现有50条“met-cloud-curated-v1”云纹观察索引不是50幅独立作品。使用 `museumObjectId` 按25件作品去重，并逐件对照 `docs/cloud-library/met-api-snapshot.json` 的 `isPublicDomain=true`、原始馆藏URL和 `primaryImageSmall/primaryImage`。再用 `imageSha256/thumbnailSha256` 校验本地 `assets/patterns/met-{id}.jpg`；不通过的不取色。构建输出才是**实际新增计数**，不可用预计25冒充已成功入库。
- **本机局部取色**：在真实开放馆藏原作卡上点击“框选局部取色”，按触屏或鼠标拖拽选区；原生 Canvas 在本机直接读取选区原始 RGB 图像像素（不是从旧六色卡插值）。选区至少12×12像素，单调区域不能提取六种不同颜色时提示扩大区域。局部色卡 JSON 保留馆藏原始出处、许可证和归一化选区坐标；可用于故事纹样。**原版六色及其固定编号不会被覆盖。** 会话配色只保存到浏览器 `sessionStorage`，仅本次浏览会话有效；并不是图像官方色卡、馆藏确认过的取样范围或丝线编号。
- **国家及艺术风格**：国家选项只显示实际带 `country` 字段的开放原作，缺失则标为未注明而非自动猜测。与原有文化地区、画家筛选分开。莫奈/梵高带明确的印象派/后印象派编辑分类，原创配色用“灵感（原创）”命名，不视为大师原作实测色。
- **色谱质量**：`npm run audit:palettes` 输出 `docs/color-atlas/palette-quality-review.json`，以 sRGB→CIE Lab 色差、六色一对一最优匹配检测精确重复、视觉近似、低对比候选及24套原创艺术风格。**算法不等于设计师审美评审**；不自动删除不同馆藏作品的配色与版权溯源，最终淘汰、替换和排序要人工验收后进行。
- **API 离线容错**：新构建请求莫奈/梵高官方数据失败时，仅复用仓库里过去实际通过许可核验、在磁盘可读取且 SHA-256 完全匹配的作品记录，避免临时网络超时删掉既有合法来源；不使用臆造图片、标题或色值。

### 开源与权威工具选型（评估参考，不等于打包引入）

- [Cropper.js](https://github.com/fengyuanchen/cropperjs) — MIT；成熟交互式裁图器。本项目目前未引入依赖，采用轻量原生 Canvas 选区以保持 GitHub Pages 离线部署简洁。
- [Color Thief](https://github.com/lokesh/color-thief) — MIT；包含六色提取与局部 region 功能。本项目并未拷贝其代码，采用现有 Pillow 全图提取以及独立的浏览器量化取样。
- [Color.js](https://github.com/color-js/color.js) — 开源色彩空间与色差工具；可作为后续人工色差标定候选。本轮质量报告通过项目本身已有的 CIE Lab 转换实现，避免新增 CDN。
- [The Met Collection API](https://metmuseum.github.io/) — 按作品 `isPublicDomain`、版权和官方图像来源判定，并且注意2026年对搜索 API 的升级（旧 /v1/search 已弃用）；本项目按对象 ID 调用 /v1/objects/[objectID]。
- [Art Institute of Chicago API](https://api.artic.edu/docs/) — 以 `is_public_domain` 与 `image_id` 为依据，官方 IIIF 只用于明确允许的馆藏图像。

### 人工验收要点

先测试“莫奈→框选局部→导出JSON→应用故事”，再检查“世界纹样→文化地区”“有馆方国家字段→国家筛选”“原创莫兰迪→艺术流派”，最后查看质量审计的低区分度与近似方案，逐个判断色序、冷暖平衡、丝线应用可读性；不把自动质量评分当人工结论。

## A/B/C 第二阶段 · 画家按姓名、全球艺术风格与文化纹样关联（2026-10-20）

### A. 画家作品：先选姓名，后看真实作品
- 首页「画家作品」是正式的**画家姓名目录**，中英文并列、使用真实馆藏原作封面；点击某姓名才进入他的具体作品与六色取样记录，并可返回所有画家。
- `scripts/world_artist_expansion.py` 维护37位跨时期、跨国家/地区的**研究候选**，候选本身不意味着授权或网站已收录：只调用 Cleveland Museum of Art 官方 Open Access API，在结果里验证逐件 `share_license_status == CC0`、馆方 `creators[].description` 明确匹配该作者、官方 CDN 图片真实存在、可成功解码并产出6种图像色；然后本地保存图片 SHA-256、藏品馆号、原题、创作时间和来源 URL。搜索命中但馆方并未署名本人、仅标“after / follower / workshop”的作品拒绝自动纳入。

### 验收与边界
- 完整流水线先生成官方博物馆图像色谱，再运行 `npm test`、`npm run build`、`npm run audit:palettes` 和真实 Chrome 浏览器交互测试。必须满足至少12位经核实的不同画家、跨越至少5个文化国家背景、69套原创风格，以及保留过去954套色谱顺序。
