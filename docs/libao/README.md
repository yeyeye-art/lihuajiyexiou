# 梨宝全站导览

梨宝负责站点使用和指路；小梨负责有出处的刺绣讲解。三个短导览仅由访客主动开始，没有收费接口或自动录音。

## 入口与状态

- 新版在 App 的全站层挂载 `LibaoGuide`。页面名称读取现有 `pageNames`，目的地与页面说明位于 `src/features/libao/guide.ts`。
- 使用原 `assets/models/libao.glb` 与现有渲染器；只按比例显示，无模型改形。小窗口为静态3D渲染，不持续运行WebGL动画。失败时显示文字梨字，导览仍可使用。
- 创作和小梨页面缩为文字入口；游戏、AR和相机试搭页面以及菜单/模态框打开时隐藏导览入口。页面隐藏时释放角色组件。
- 免打扰只将 `quiet` 写入 `lihuaji.libao.preferences.v1`。它收起形象，保留帮助入口，不访问或清除游戏与云存档。
- 页面帮助和提问仅为本地规则与明确入口，没有通用模型问答承诺。输入不上传、不放进URL、不持久化。
- 交给小梨时用一次性页面内存传递，填入输入框后由访客确认发送；不自动提问。

## 三条路线与真实完成条件

1. 初次访问：主页 → 纹样搜索/筛选 → 译绣的两种模式 → 小梨。
2. 照片转化：图片读取成功 → 实际生成参考稿 → 真实SVG/CSV下载入口。不会替访客勾选图片权限，也不会自动下载。
3. 学滚针：访客发送预填问题并获得新的滚针资料回答 → 阅读与出处 → 对应滚针练习出现真实播放进度。导览完成不等于学会针法。

Driver.js 1.12.1 用于高亮、浮层及键盘交互；应用自己的状态负责跨页、取消与任务门槛。未找到目标会在15秒后显示重试/停止，不显示假高亮，不标记完成。旧请求与浮层在换步、关闭和离开时清理。公开API依据：https://driverjs.com/docs/configuration 。

## 验证

运行 `npm run typecheck`、`npm test`、`npm run build`。单元测试核对真实路由、两种译绣模式、原问题转交、未知问题边界、操作门槛和免打扰页面。

真实浏览器验收可在具备Python Playwright与Chromium的环境运行：

```sh
python scripts/libao.acceptance.py --url https://yeyeye-art.github.io/lihuajiyexiou/ --output outputs/libao
```

可通过 `--browser` 指定已有Chromium可执行文件。验收实际执行示例图转稿、下载SVG、滚针播放，并检查390px手机布局、键盘阻止跳步、来源问答转交、异常目标重试、关闭遮罩、免打扰与本机存储保持。脚本保存截图和结果JSON，不使用真实个人照片。

原文化资料、游戏关卡、模型文件和云服务不在本轮修改范围。旧 `assets/agents/libao-knowledge.js` 仅供历史兼容，其过时入口和能力说明同步修正；新版不加载它。
