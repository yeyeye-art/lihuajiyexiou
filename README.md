## 2026-10-27 前端现代化框架重构 (React + TypeScript + Vite)

项目全面升级为现代前端组件化架构，采用 **React 18/19 + TypeScript + Vite** 进行单页应用（SPA）重构，兼具现代工程化体验与极佳的运行性能：

- **组件化与强类型架构**：业务视图与通用 UI 全面抽象解耦至 `src/components/` 与 `src/pages/`，引入严格的 TypeScript 类型接口（`src/types/`）规范纹样、文创、苏绣源流与知识库数据结构。
- **纯静态与 GitHub Pages 深度兼容**：Vite 构建基址为 `/lihuajiyexiou/`；业务素材与 JSON 使用相对路径，Hash 路由支持 GitHub Pages 子目录刷新；恪守零服务器（Zero-Server）原则，不设任何 `/api` 或假登录，照片转稿、FaceMesh 跟脸试戴与 AR 追踪完全在用户本地浏览器安全沙箱内执行。
- **完整保留文化资产与核心引擎**：
  - **1,088 份**传统与馆藏纹样分类检索及原许可链接
  - **75 件**苏绣文创资料及规格联动搭配
  - **85 条**官方来源核验苏绣非遗与针法标准资料库
  - **AR 绣境 V2**（MindAR + Three.js 分层识别与动效）
  - **数字针迹实验室**（散套、平绣、套针、滚针微观针迹模拟）
- **统一构建与自动化测试管道**：`npm run build` 保持严谨的数据源一致性与文件完整性校验，并无缝串联 Vite 打包至 `_site/` 发布目录；自动化单元测试套件（59 项测试）**100% 通过**。
- **团队协作与 GitHub CLI 开发规范**：详见 [CONTRIBUTING.md](CONTRIBUTING.md)，支持全流程通过 `gh` 命令行完成分支管理、本地守门员校验与 PR 合并发布。

## 本地开发与构建指引

开发环境要求：Node.js 24（与 CI 一致）。

```bash
# 1. 安装项目依赖
npm ci

# 2. 启动本地开发服务器（支持 HMR 热更新）
npm run dev

# 3. 运行完整自动化测试套件（59 项单元测试与文化资产校验）
npm test

# 4. 执行全量数据校验并构建生产版本（输出至 _site/ 目录）
npm run build
```

## 朋友如何协同修改

所有者打开 https://github.com/yeyeye-art/lihuajiyexiou/settings/access ，点击 **Add people**，填写朋友的 GitHub 用户名。朋友接受邀请后即可编辑文件。

- `src/`：页面交互与组件源码（React 18/19、TypeScript）。
- `style.css`、`pages.css`：全站样式与主题排版。
- `content/site.json`：首页标题、简介、顶部提示。
- `content/patterns.json`：1088 份纹样说明、地区、原出处与许可。
- `content/products.json`：75 件文创资料及规格，仅展示，无交易。
- `content/suxiu-knowledge.json`：85 条官方核验苏绣知识记录。
- `assets/`：网页图片、3D 纹样资源及浏览器运行库。

网页编辑：打开文件 → 铅笔图标 → 修改 → **Commit changes**。提交到 main 自动发布。若提交到其他分支，创建 Pull Request，审核并合并到 main 后发布。

发布进度：https://github.com/yeyeye-art/lihuajiyexiou/actions 。`Deploy to GitHub Pages` 绿色成功后刷新网站；也可点此工作流 → **Run workflow** 手动发布。工作流会先检查目录与图片引用；失败时查看红色步骤，修复后再次提交。
